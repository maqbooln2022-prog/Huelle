# Hülle

Minimalist, Scandinavian-inspired e-commerce frontend for a mobile case brand. Built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, Radix UI, and Lucide icons.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **UI primitives:** Radix UI, Lucide Icons

## Structure

- `app/` — routes, layout, global styles
- `components/` — Header, Hero, BestSellers, ProductCard, CustomizerBanner, CartDrawer, Footer
- `lib/` — cart state (`cart-context.tsx`), product data, utilities
